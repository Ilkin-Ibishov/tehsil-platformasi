# Taxonomy Triage & Self-Healing Governance

A protocol and automated runbook for inspecting, clustering, and resolving self-healing taxonomy entries registered by `trg_register_topic_code` and `trg_register_error_code` into `public.topic_codes` and `public.error_codes`.

---

## 1. Architectural Context

To protect the live student path from HTTP 500 crashes when an LLM produces an unknown topic or error code, database triggers automatically insert unknown codes with:
- `active = false`
- `needs_review = true`
- `title_az = code`

These rows appear in the `public.v_taxonomy_review` view:
```sql
select * from public.v_taxonomy_review;
```

---

## 2. Triaging Workflow

### Step 1: Inspect Live Review Queue
Query Supabase using the MCP `execute_sql` tool:
```sql
select nov, code, title_az, active, needs_review from public.v_taxonomy_review;
```

### Step 2: Execute Automated Triage Analysis
Run the clustering engine:
```bash
node scripts/triage-taxonomy.mjs --save
```
This inspects lexical similarities, domain prefix conflicts (e.g. `VEC` vs `GEO`), and proposes:
1. **Adoptions (`ADOPT`)**: Legitimate DİM topics with curated Azerbaijani titles.
2. **Merges (`MERGE`)**: Redundant or synonym codes mapped to canonical counterparts.
3. **Domain Conflicts**: Inconsistent prefixes (e.g. `VEC.OPERATIONS` vs `GEO.VECTORS`).

### Step 3: Decision Rules
- **ADOPT**: If the code represents a genuine topic in Azerbaijani secondary school math/physics (e.g. `GEO.TRIANGLE_ANGLES` ➔ "Üçbucağın bucaqları"), approve it:
  ```sql
  update public.topic_codes
  set active = true, needs_review = false, title_az = 'Üçbucağın bucaqları'
  where code = 'GEO.TRIANGLE_ANGLES';
  ```
- **MERGE / ALIAS**: If the code is a duplicate or synonym (e.g. `GEO.SOLID_CONE_VOLUME` vs `GEO.CONE_VOLUME`), mark it inactive and resolved:
  ```sql
  update public.topic_codes
  set active = false, needs_review = false
  where code = 'GEO.SOLID_CONE_VOLUME';
  ```
- **PROMPT REPAIR**: If LLMs consistently invent a forbidden or fragmented code (e.g. `ALG.PARABOLA_VERTEX` instead of `ALG.QUADRATIC_FUNCTION`), add an explicit mapping or canonical example in `prompts/solve/math.md`.
